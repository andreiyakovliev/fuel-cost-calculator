# Fuel Cost Calculator

This simple web app calculates the total fuel cost based on distance, fuel consumption, and fuel price.

## Features

- Input fields for:
  - Fuel consumption per 100 km
  - Distance (in kilometers)
  - Fuel price per liter
- Calculates cost on button click
- Minimal and responsive design

## Technologies

- HTML
- CSS
- JavaScript (vanilla)
